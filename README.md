# Proyek Web AMR

Proyek ini adalah aplikasi web berbasis **Django** yang mengintegrasikan sistem informasi berita di halaman depan serta menampilkan data mahasiswa secara real-time dari database menggunakan **DataTables AJAX**.
---

## 🚀 Cara Menjalankan Project (Untuk Penguji)

Pastikan Python sudah terinstal. Buka terminal/CMD di dalam folder project ini, lalu jalankan perintah berikut secara berurutan:

   
1. Jalankan server lokal Django: ```bash
   python manage.py runserver

2. Buka browser dan akses: http://127.0.0.1:8000/

3. 🔑 Akses Admin Panel:
   URL: http://127.0.0.1:8000/admin/
